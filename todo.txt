- ✅ 回复邮件功能：指定客服 / 客户接口人 为主收件人（另一方自动抄送）；引用只带邮件头部；
    一键把正文与标题翻译为英文；窗口与提新工单统一风格。

2. 巨型类拆分：WorkflowService(≈1340)/MainViewModel(≈1500)/MainWindow.xaml.cs(≈1680) 行数过大，
   → 按 同步 / 发信 / 联系人 / 导出 拆成独立服务，UI 业务逻辑逐步下沉 VM。
3. 主题解析 SubjectParser.ProductAliases 仅硬编码 EC/OPM，新产品简称需追加或改为可配置。
4. 关注客服邮箱为空时当前会全量采集邮件（IsMonitored* 直接返回 true）——
   若需限制，在 UI 上明确提示“未配置客服邮箱时拉取全部邮件”。
5. 大量 UI 事件为 async void + 空 catch（MainWindow.xaml.cs）——逐步改为可等待、可留痕。
